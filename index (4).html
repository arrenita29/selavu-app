Phone setup: add SMS entries automatically

Each phone gets its own token. The token is a password for adding entries to your account: keep it private.

Copy it now and paste it into your Shortcut. After you leave this page it cannot be shown again.

iPhone (Shortcuts)

  1. Shortcuts, then Automation, then New Automation, then Message.
  2. Message Contains debited, then Run Immediately. Make a second one for credited if you want money received too.
  3. Action 1, Get Contents of URL: paste the Function URL, tap Show More, Method POST, Header x-selavu-token with your token, Request Body JSON with a Text field sms set to Shortcut Input.
  4. Action 2, Get Dictionary Value for the key message from Contents of URL.
  5. Action 3, Show Notification with that value.

Android

Use an automation app such as MacroDroid or Tasker: when an SMS containing "debited" or "credited" arrives, send an HTTP POST to the Function URL with the header x-selavu-token and a JSON body {"sms": "the message text"}. Menu names differ between apps.
